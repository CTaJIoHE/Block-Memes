# 🧩 Block Memes — Indie Puzzle Game

**Block Memes** — это динамичная логическая игра-головоломка, вдохновленная классическим геймплеем *Block Blast*, но переосмысленная в шуточной форме с глубокой интеграцией интернет-культуры. Проект разработан на языке **Python** с использованием библиотеки **Pygame**.

> **Автор проекта:** Мишустин Данил
> Данная работа выполнена в рамках практической части учебной практики (ПМ.01 Разработка программных модулей) в КГБПОУ «ААСК».

---

## 🌟 Ключевые особенности

* **🎮 Умный геймплей:** Три режима сложности (6x6, 8x8, 10x10) с адаптивной сеткой.
* **🎭 Система мемов:** Случайные блоки могут превращаться в мемы! При их установке проигрываются легендарные звуковые эффекты.
* **🛠️ Кастомизация (UGC):** Встроенная возможность импортировать **собственные** мемы (изображения и звуки) через нативный проводник Windows.
* **✨ Визуальные эффекты:**
    * Псевдо-3D логотип в главном меню.
    * Система частиц при уничтожении линий.
    * Интерактивные элементы интерфейса с плавными анимациями.
* **💾 Сохранение прогресса:** Полная история игр, рекорды и внутриигровая валюта сохраняются в `data.json`.
* **🛡️ Anti-Rage Quit:** Система подтверждения выхода с радиальным таймером удержания.

---

## 🐞 Режим отладки (Debug)

Для быстрой проверки функционала магазина и покупки мемов (без необходимости долгого накопления валюты) в игре предусмотрен скрытый **чит-код**.

**Инструкция по активации:**
Ввод осуществляется прямо во время игры или в меню:

1. Нажмите клавишу **`Enter`**.
   *(Это действие очищает буфер ввода от возможных ошибок или случайно нажатых ранее клавиш).*
2. Введите на клавиатуре слово: **`privet`**
   *(Ввод происходит «вслепую» и не отображается на экране).*
3. Снова нажмите **`Enter`** для подтверждения.

> **Результат:** Вам будет начислена сумма монет, равная стоимости одного мема.
> *Используйте эту функцию исключительно для отладки и тестирования.*

## 🚀 Установка и запуск

### 📥 Способ 1: Быстрый запуск (Windows) — Рекомендуется
Для запуска игры **не требуется** установка Python.

1. Перейдите в раздел **Releases** (справа на странице репозитория).
2. Нажмите на **Assets** и скачайте архив `Source code (zip)` 
3. или специально подготовленный архив с названием версии (например, `Block-Memes-1.0.zip`).
4. **Распакуйте** скачанный архив в любое удобное место.
5. Откройте папку и запустите файл `block_memes.exe`.

> ⚠️ **Важно:** При запуске Windows может показать окно **SmartScreen** ("Система Windows защитила ваш компьютер").
> Это происходит, так как у приложения студенческая лицензия без цифровой подписи.
> Чтобы играть, нажмите **«Подробнее»** -> **«Выполнить в любом случае»**.

### 💻 Способ 2: Для разработчиков (Source Code)

Если вы хотите изучить код или изменить его.

**Требования:**
* Python 3.10 или выше
* Установленная библиотека Pygame

**Инструкция:**

1. **Клонируйте репозиторий:**
```bash
git clone [https://github.com/ваш-никнейм/block-memes.git](https://github.com/ваш-никнейм/block-memes.git)
cd block-memes

```

2. **Установите зависимости:**

```bash
pip install -r requirements.txt

```

3. **Запустите игру:**

```bash
python "block memes.py"

```
Либо просто скачайте файл с именем block_memes.py и проведите листинг

## 🏗️ Технический стек

* **Core:** Python
* **Graphics & Sound:** Pygame
* **System UI:** Tkinter (для диалоговых окон выбора файлов)
